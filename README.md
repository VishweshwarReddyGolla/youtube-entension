# YouTube Focus Mode – Chrome Extension

A Chrome extension to block YouTube’s home feed, allow search-only learning, and remove distracting UI elements.

## Features
- Blocks YouTube home feed
- Custom search-only interface
- Hides sidebar on search results
- Enable/Disable toggle
- Time-based focus mode

## Tech Stack
- JavaScript
- Chrome Extension APIs
- HTML5
- CSS

## How to Use
1. Clone the repo
2. Open `chrome://extensions`
3. Enable Developer Mode
4. Load unpacked → select project folder
